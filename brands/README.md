# Brand Assets — Emprega+ Umbrella

Central hub for all brand documentation across the Emprega+ product family.

## Structure

```
brands/
├── emprega-mais/    Emprega+ parent brand (B2B/B2G)
├── pdv/             Profissional de Valor (B2C sub-brand)
└── electia/         Electia by Emprega+ (B2B SaaS assessments)
```
