# Brand Starting Point — ResultX Ecosystem

> Inventário prático do que já existe construído por marca, com os caminhos mais úteis para retomar trabalho sem perder tempo procurando peça solta.
>
> Escopo: `Emprega+`, `EditalHub`, `PdV` e `ResultX Consultoria`.

## Como ler este documento

- `Canonical` = fonte principal da marca.
- `Adjacent` = material útil, mas derivado ou de contexto próximo.
- `Legacy` = peça antiga, ainda útil como referência, mas não como base final.

## 5. Ordem recomendada para retomar

1. Emprega+ e EditalHub juntos, porque compartilham a mesma fundação visual.
2. PdV, porque já tem pacote editorial e operacional bastante maduro.
3. ResultX Consultoria, porque precisa virar vitrine mais clara de portfólio e prova de autoridade.

## 6. Regra prática

- Se a peça for pública e institucional, comece pelo brand book da marca.
- Se a peça for produto, vá para tokens, previews e docs de design system.
- Se a peça for conteúdo, vá para os guias sociais e templates.
- Se a peça for consultoria, use os brand assets de ResultX como guarda-chuva e os cases em `consulting/` como prova.
